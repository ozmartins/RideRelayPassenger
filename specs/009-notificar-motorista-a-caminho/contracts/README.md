# Contratos desta feature

Esta feature não define um kind novo: `kind: 20005` já existe (emenda 08, feature 010 do
motorista). Uma nova emenda (10) só registra o consumo pelo passageiro.

Ver `../../../driver/specs/002-nostr-relay-connection/contracts/nostr-events.md` (arquivo
canônico, mesmo já usado por todas as emendas anteriores) — seção *Conteúdo do kind 20005 —
Localização do motorista*, a atualizar durante a implementação desta feature com um parágrafo
"Consumo pelo passageiro (emenda 10)", replicado na mesma alteração em
`Prototipo/passenger/specs/002-nostr-relay-connection/contracts/nostr-events.md` (Princípio IV) —
e seção *Forma da inscrição*, cuja lista de kinds do passageiro passa a incluir `20005`.
